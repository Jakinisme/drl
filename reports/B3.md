Test result: `pytest tests -q` → **101 passed** (79 pre-existing + 22 new).
Simulation-only. No number in this report is a claim about the real vessel — the physical
model is placeholder-parameterised (`SYSID.md`), so these are arithmetic checks.

## Metric definitions

All functions take numpy arrays **or** torch tensors (duck-typed on `.detach()`, so no
torch import) and return numpy/float. `evalkit.metrics` imports numpy only; `matplotlib`
is imported solely by `evalkit.plots`, forced to `Agg` before pyplot (test asserts both).

| metric | signature (CONTRACT §4.9) | formula | unit |
|---|---|---|---|
| radial error | `radial_error(xy[T,2], goal_xy[T,2] or [2]) -> [T]` | `e_t = ‖xy_t − goal_t‖₂` | m |
| mean / p95 | `mean_p95(err) -> (float, float)` | arithmetic mean; `np.percentile(e, 95)` = **linear interpolation**, not nearest-rank | m |
| cross-track | `cross_track_rmse(xy[T,2], path[P,2]) -> float` | `√(mean_t d_t²)`, `d_t` = point-to-**segment** distance to the polyline, projection clamped to `[0,1]`; `P == 1` → distance to that point | m |
| settling time | `settling_time(t[T], err[T], tol, hold_s=5.0) -> float` | `t[i] − t[0]` where `i` = first sample after the **last** out-of-band sample; `inf` if the in-band tail is shorter than `hold_s` or the trace ends out of band | s |
| energy | `energy(t[T], action[T,3]) -> float` | `∫ Σ_i a_i(t)² dt`, trapezoid | dimensionless·s |
| action rate | `action_rate(t[T], action[T,3]) -> float` | `Σ_t ‖a_t − a_{t−1}‖₂ / (t[-1] − t[0])` (total variation per second) | 1/s |
| summary | `summarize(traj, tol=None, hold_s=5.0) -> dict` | all of the above | — |

Decisions worth knowing:

- **p95 = linear interpolation** (`numpy` default). For `arange(100)` it is `94.05`, not
  `94`. Nearest-rank would report the 95th observed value; the interpolated one is the
  smoother statistic and is what `np.percentile` gives by default. Documented in the
  docstring because the two differ on discrete samples.
- **settling time = entry into a band it never leaves**, measured from `t[0]`. `hold_s`
  does not search for a "long enough" in-band run earlier in the trace; it only rejects
  traces whose tail is shorter than `hold_s` (short episodes). One rule, no double
  counting. `NaN` is treated as out of band (`~(e <= tol)`), so a dead estimator can never
  look settled.
- **energy and action rate are on the normalized command** in `[-1, 1]`, per CONTRACT
  §4.9. Joule-equivalent numbers need per-motor `thrust² · max_thrust²` — **TODO** decided
  in Wave 4, not here (`sim/thrusters.py` owns the motor model).
- **action rate is time-normalized total variation**, so uneven `dt` (dropped policy steps,
  GPS-rate logging) does not silently change the score. A step of `‖Δa‖ = 1` over 2 s
  scores `0.5 s⁻¹` regardless of the sample count.
- **`summarize` path for cross-track**: `traj["path"]` if given, else the ordered unique
  `goal_xy` rows. That is the waypoint sequence for waypoint episodes and the single hold
  point for station keeping (cross-track then degenerates to radial error — intended).
- `traj["psi"]` and `traj["mode"]` are accepted but unused: §4.9 specifies no heading
  metric, and the whole trace is scored regardless of mode. If per-mode splits are wanted,
  slice the dict before calling — **TODO** for Wave 4 if the results table needs it.
- Default tolerance for `settling_time` inside `summarize`: `traj["tol_m"]`, else **1.0 m**
  (a placeholder, not a requirement).

## Plots (`evalkit/plots.py`)

`plot_error(traj, tol=None, ax=None, out=None)` — radial error vs time + tolerance line.
`plot_trajectory(traj, ax=None, out=None)` — XY in local ENU, east right / north up, equal
aspect, start/end/goal markers, optional `path` dashed.
`summary_table({"pid": summarize(...), "ppo": summarize(...)}, out=...)` — one row per run,
scalar metrics only.

Each returns the `Figure` and writes a PNG (dpi 120) when `out` is passed. Backend `Agg`,
no window, safe headless.

## Test cases (`tests/test_metrics.py`, 22 tests, hand-computable)

Synthetic trajectories only, values checked by hand:

- radial error: `[[0,0],[3,0],[0,4]]` against the origin → `[0, 3, 4]`; single-goal
  broadcast → `hypot(3,4) = 5`.
- mean/p95: ramp `0..99` → mean `49.5`, p95 `94.05` (linear interpolation); constant array →
  `(2,2)`; one sample → itself; `[0,10]` → p95 `9.5`; NaN dropped; empty → `(nan, nan)`.
- cross-track: 1 m offset ±1 → RMSE 1; constant 0.5 m → 0.5; beyond the segment end
  (`[13,4]` past `x≤10`) → 5 (clamp, not distance to the infinite line); on-path → 0;
  `P == 1` → 5.
- settling: out-of-band first 4 samples of a 0.5 s grid → `2.0 s`; same trace with
  `hold_s=10` → `inf`; error rising again at the end → `inf`; `NaN` at the end → `inf`;
  already inside the band → `0.0`.
- energy: constant 0.5 on 3 axes for 10 s → `3·0.25·10 = 7.5`; zeros → 0; single sample → 0;
  `1.0` for 2 s → `2.0`.
- action rate: single unit step over 2 s → `0.5`; constant → 0; `Δa = (0.6, 0.8, 0)` → L2
  norm 1 → `1.0`.
- summarize: circle of radius 2 around the hold point → every radial metric and cross-track
  = `2.0`, energy/action rate 0, settles at 0 with `tol=3`, `inf` with `tol=1`; straight
  track 0.5 m off a two-waypoint path → cross-track `0.5`, explicit `path` overrides the
  derived one → `9.5`.
- hygiene: `import evalkit.metrics` in a fresh interpreter leaves `matplotlib` out of
  `sys.modules`; `evalkit.plots` runs on `Agg` and the three helpers write non-empty PNGs.
