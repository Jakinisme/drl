## 2. Architecture (`models.py`, CONTRACT §4.7)

| item | value |
|---|---|
| input | `obs [B,150]` (= 15 raw x K=10 history, already normalized by the env, clip ±5) |
| normalization | `(obs - obs_mean) / obs_std` as float32 buffers, default 0/1; baked into the module so C3's ONNX export can read the same constants |
| trunk | `Linear(150,256) → ELU → Linear(256,128) → ELU → Linear(128,128) → ELU` (`hidden: [256,128,128]`, `activation: elu`, both from yaml) |
| heads | mean `tanh(Linear(128,3))` (gain 0.01), value `Linear(128,1)` (gain 1.0), `log_std` a 3-vector `nn.Parameter`, init `-0.5` |
| output | `forward -> (mean [B,3] in [-1,1], value [B,1], std [B,3] = exp(log_std))` |
| params | **88,583 trainable** (88,883 incl. the two 150-long buffers); 1.08 MB checkpoint incl. Adam state |
| sampling | `a = clamp(mean + std*eps, -1, 1)`; log-prob is the plain Gaussian density of that clamped action, so rollout and update use one formula. **No tanh-Jacobian correction** (documented simplification, CONTRACT §4.7) |
| init | orthogonal, hidden gain `sqrt(2)`, mean-head gain 0.01 |

`gaussian_log_prob()` is shared by `PolicyNet.log_prob` and the PPO update; it is asserted
equal to `torch.distributions.Normal(...).log_prob` in the tests. Entropy uses
`H = Σ(log σ + 0.5·log(2πe))` (constant `1.4189`, not the 0.9189 log-density constant).

## 3. Trainer (`train.py`)

- `PPOTrainer(cfg, env=None, writer=None)`; `env=None` builds the real `AsvEnv`, so tests
  inject a dummy env and no GPU is touched.
- Rollout buffer `[T, N, ...]` preallocated on the device: obs, action, logp, value,
  reward, done. GAE(λ) with `live = 1 - done` (the env auto-resets, so the value of the
  post-reset obs is masked, never bootstrapped across an episode boundary).
- Update: epochs x minibatches over shuffled flat `[T*N]`; clipped surrogate
  `-min(r·A, clip(r)·A)`, value MSE on GAE returns, `-entropy_coef·H`, global grad-norm
  clip, Adam. Advantage normalization optional (`normalize_advantage: true`).
- Linear LR anneal `lr → lr*lr_min_frac` over `total_steps`; logged every iteration.
- TensorBoard: `train/{reward, return, pi_loss, v_loss, entropy, kl, clip_frac, lr,
  steps_per_s, iteration}`.
- Checkpoints: `ckpt_<steps>.pt` every `save_interval_steps` + `ckpt_last.pt` at the end;
  contents `{model, optimizer, steps, iteration, cfg}`; `--resume` restores all of it.
- CLI: `--config --total-steps --iterations --num-envs --device --seed --log-dir
  --ckpt-dir --resume`.
- No hyperparameter is hard-coded outside `configs/train.yaml`; `train.DEFAULTS` only
  mirrors it for hand-written dicts and yaml keys that are omitted.
- `dtype` from yaml (`float32`/`float64`); `device: cuda` falls back to CPU only when CUDA
  is unavailable.

## 6. Assumptions / deliberate simplifications

1. **Clamp instead of tanh bijection for the log-prob** — CONTRACT §4.7 explicitly allows
   this. Consequence: actions pinned at ±1 get a distorted log-prob; measured clip_frac
   at init is 0.04–0.07, so it is not dominant.
2. **No value clipping, no KL early-stop, no observation running-statistics pass.** The env
   already normalizes (CONTRACT §5) and `obs_mean/obs_std` default to 0/1. Add a
   running-stat pass only if C1/C2 shows oscillation (`kl` was 0.003–0.008 at lr 3e-4 here).
3. **`env_config`/`vehicle_config`/… yaml paths are read by the env, not by `train.py`**:
   only `env_config` is loaded (and passed as a dict); `AsvEnv` loads the other three from
   the same `configs/` defaults. If B1 ever changes those defaults, pass them explicitly in
   `build_env`.
4. **Bootstrap uses the auto-reset obs masked by `(1-done)`**, per CONTRACT §4.5. Fine for
   PPO but makes the very last value of an episode unreachable — expected.
5. **`steps_per_s` is cumulative** (total steps / elapsed), not an instantaneous rate.
6. Config keys added on top of CONTRACT §3.5 (**no existing key renamed**): `lr_schedule`,
   `lr_min_frac`, `normalize_advantage`, `log_interval`, `obs_mean`, `obs_std`.
